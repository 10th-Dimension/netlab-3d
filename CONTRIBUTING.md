# Contributing to NetLab 3D

Issues, factual corrections, accessibility improvements, and focused new labs are welcome.

1. Describe the behavior a student should observe and cite a protocol specification or authoritative technical reference.
2. Keep the scenario text, topology, device state, and packet steps consistent.
3. Add or update a test for changes to routing, addressing, faults, or packet paths.
4. Run `pnpm test` and `pnpm run build` before opening a pull request.

Please avoid adding real credentials, school records, or private network details to issues or pull requests. This project uses documentation addresses and fictional lab hosts.
